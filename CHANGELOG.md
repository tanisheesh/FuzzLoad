# Changelog

All notable changes to **FuzzLoad** are documented here.

---

## [1.0.0] — 2026-10-27

### ✨ Added
- 5-Layer Takagi-Sugeno Adaptive Neuro-Fuzzy Inference System (ANFIS) with online gradient descent parameter learning
- Tree-based Genetic Programming (GP) symbolic regression engine with Digital Twin 60-second replay buffer evaluation
- High-throughput Go reverse proxy data plane (`httputil.ReverseProxy`) and heterogeneous 4-node worker cluster
- FastAPI AI Control Plane coordinating 500ms ANFIS fast loops and 6s GP evolutionary loops
- Next.js 16 real-time observability dashboard with live topology, Gaussian membership curves, GP syntax tree inspector, chaos fault injection, and multi-algorithm benchmark runner
- Multi-stage Docker and `docker-compose.yml` deployment for AWS EC2 Free Tier and Render
